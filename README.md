# Система сопровождения мероприятий

Учебный frontend-прототип на HTML5, CSS3 и JavaScript без сторонних библиотек.

## Локальный запуск

Откройте `index.html` в браузере. Установка зависимостей и локальный сервер не требуются.

## Публикация на GitHub Pages

1. Загрузите содержимое проекта в корень репозитория GitHub.
2. В настройках репозитория откройте раздел **Pages**.
3. Выберите публикацию из ветки `main` и каталога `/ (root)`.

Все пути к стилям и скриптам относительные, поэтому дополнительная настройка перед публикацией не нужна. Файл `.nojekyll` отключает обработку Jekyll.
